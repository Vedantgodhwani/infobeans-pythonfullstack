### 1. Bank Loan Approval System
```python
salary = 40000
credit_score = 720
existing_loans = 1

if salary >= 30000:
    if credit_score >= 750:
        print("Loan Status = Approved")
    else:
        if existing_loans < 2:
            print("Loan Status = Conditional Approval")
        else:
            print("Loan Status = Rejected")
else:
    print("Loan Status = Rejected")
```

### 2. E-Commerce Discount Engine
```python
cart_value = 6000
user_type = "Premium"

if cart_value >= 5000:
    if user_type == "Premium":
        final_amount = cart_value * 0.80
    else:
        final_amount = cart_value * 0.90
else:
    if cart_value >= 2000:
        final_amount = cart_value * 0.95
    else:
        final_amount = cart_value

print(f"Final Amount = {final_amount}")
```

### 5. ATM Withdrawal System
